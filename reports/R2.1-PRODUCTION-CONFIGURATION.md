# R2.1 Production Configuration — PlayAIG V1.0

## 1. 完成内容

- 将正式生产 URL 统一为 `https://playaig.com`。
- 将全站 metadata、Canonical、Open Graph、Twitter、JSON-LD、Sitemap、robots、RSS 与 OpenSearch 的发布 URL 统一为 PlayAIG 正式域名。
- 完成 PlayAIG 主站 metadata 与品牌声明：`PlayAIG — Verified Game Wikis, Guides and Databases`。
- 补齐 manifest、favicon、Apple Touch、Android manifest icons、mask icon 与 OpenSearch link。
- 新增只包含公开 URL 的开发、生产和示例环境配置；未加入任何 secret、API key 或 token。
- 重新构建并执行全部既有验证与生产 URL 扫描。

## 2. 文件变更

- `src/app/site.ts`：PlayAIG site origin、Organization / WebSite JSON-LD、绝对 Canonical、OG、Twitter 与 JSON-LD URL。
- `index.html`：PlayAIG title / description / keywords、favicon、Apple Touch、mask icon、manifest、OpenSearch 声明。
- `public/site.webmanifest`：PlayAIG 名称、scope、颜色与 Android icon entries。
- `public/icons/favicon-32.png`、`public/icons/apple-touch-icon.png`、`public/icons/playaig-icon-192.png`、`public/icons/playaig-icon-512.png`：从既有官方 SpiritVale 品牌图标转换的发布图标，无 AI 或第三方图片。
- `.env.example`、`.env.development`、`.env.production`：公开的正式 Site URL 配置，无秘密值。
- `scripts/generate-spiritvale-seo.mjs`、`scripts/prerender-spiritvale-*.mjs`：生产域绝对 URL、PlayAIG social brand、Organization / WebSite metadata。
- `scripts/validate-spiritvale-*.mjs`：绝对 Canonical 与生产 URL / social branding 验证。
- `schemas/spiritvale/*.json`：Schema `$id` 从保留示例域改为 `https://playaig.com/schemas/...`。
- `public/sitemap.xml`、`public/robots.txt`、`public/rss.xml`、`public/opensearch.xml`：由最终 production build 重新生成。

## 3. Site URL 检查

- `SPIRITVALE_SITE_URL`、`SITE_URL`、`BASE_URL`、`SITE_ORIGIN` 在 `.env.example`、`.env.development`、`.env.production` 均为 `https://playaig.com`。
- 生成器默认值亦为 `https://playaig.com`，不再回退到示例域。
- 对 `public`、`src`、`scripts`、`schemas`、`index.html` 与环境配置完成扫描：`spiritvale.example`、`example.com`、`localhost`、`127.0.0.1` 均为 0。
- 本地开发命令中的 loopback host 不属于生产 metadata / 发布产物，未进入上述生产配置范围。
