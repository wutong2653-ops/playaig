Taxonomy IDs are also stable relations: roles, stats, weapons, elements, rarities, equipment types, skill types, build purposes, game stages, play modes, map types, monster types, spawn types, and guide types. They are intentionally not bound to a formal SpiritVale entity until a source confirms the relationship.
